# Contributing

Thank you for improving EventFlow. Keep changes focused, typed, accessible, and free of credentials.

1. Create a branch from the current default branch.
2. Install dependencies with `npm install`.
3. Use mock mode for local work; never commit `.env.local`.
4. Add or update tests for behaviour changes.
5. Run `npm run lint`, `npm test`, `npm run build`, and `npm run format:check`.
6. Describe the user impact, test evidence, and any future AWS contract changes in the pull request.

Use uppercase API status values, central formatter/derivation utilities, and the service layer for network access. Preserve keyboard navigation, visible focus, labels, error associations, reduced motion, and responsive layouts.
